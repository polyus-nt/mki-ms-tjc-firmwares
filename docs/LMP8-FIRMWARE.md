# Документ перенесён

В ФабЛаб используется обычная трёхвыходная лампочница tjc-ms1-lmp-a3,
а не lmp8. Актуальное описание: [LMP-FIRMWARE.md](LMP-FIRMWARE.md).

Восьмилампочница остаётся только в химреакторе:
[его распиновка и полярность](../chem-reactor-теплица/PINOUT.md).
Старые образы build/lmp8 из корневой сборки ФабЛаб больше не использовать.
