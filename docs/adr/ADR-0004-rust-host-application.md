# ADR-0004: Развивать ПК-приложение на Rust

## Status

Accepted

## Context

В `tjc-commutator` одновременно находятся Python- и Rust-реализации приложения мониторинга. Параллельное развитие обеих реализаций потребовало бы дублировать декодирование протокола, телеметрию, интерфейс оператора и агентный контур. История проекта показывает, что актуальные продуктовые изменения выполняются в Rust-версии.

## Decision

Rust-приложение из `tjc-commutator/src/main.rs` является единственным продуктовым ПК-приложением. В нём развиваются интерфейс оператора, постоянное хранилище телеметрии и локальный MCP-сервер. Оно владеет COM-портом и выполняет обработчики инструментов, но не реализует собственный цикл взаимодействия с моделью.

Python-файлы не являются второй продуктовой реализацией. Они могут временно сохраняться как явно обозначенные диагностические утилиты для работы с последовательным портом.

## Consequences

Протокол и пользовательское поведение имеют одну основную реализацию. Новые функции не требуется синхронизировать между двумя GUI-приложениями.

Для Rust-приложения потребуются библиотеки работы с SQLite, локальным HTTP/MCP и сериализацией данных. Существующую README-документацию, которая описывает запуск Python GUI, необходимо привести в соответствие с продуктовой реализацией.
