# Domain context

## Glossary

### Аппаратный API

Программный доступ к показаниям датчиков и управлению исполнительными
устройствами теплицы. Не является температурным регулятором.

### Арбитр аппаратного обмена

Центральная плата МС-ТЮК, определяющая порядок обращений к аппаратным узлам.

### Командный пайплайн

Единичное выполнение команды аппаратной системой, охватывающее запрошенное
действие и его итоговый результат. Результатом может быть как успешный ответ,
так и ошибка.

### Таймаут аппаратного обмена

Истечение предельного времени ожидания результата команды. Не является
обязательной паузой перед обменом или после получения ответа.
