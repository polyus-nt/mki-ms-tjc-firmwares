# Runtime МС-ТЮК

Источник: https://github.com/kruzhok-team/lapki-compiler
Ревизия: `c0e235f364f21b1a7ba8dbb598ef0bc983511af6`.
Скопированы только 15 файлов, необходимых рукописным прошивкам, из
`compiler/library/tjc-ms1-ard-a1/1.0/source/`. Для main-a4 используемые 13
общих файлов побайтно совпадают с `compiler/library/tjc-ms1-main-a4/1.0/source/`.
ArduinoAdapter.hpp и arduino_link.c в сборку хаба не входят.

Для кнопочницы импортирован неизменённый `Button.hpp` из
`tjc-ms1-btn-a2/1.0/source/` той же ревизии. SHA-256 закреплён в
`scripts/build_buttons.py`. Все используемые кнопочницей общие 13 файлов
побайтно совпадают с этой платформой. Button задаёт входы без подтяжек;
прошивка после конструкторов включает внутренние pull-up для сухих контактов.
Сам импортированный класс не изменён, его `scan()` и `isPressed()` используются
для подавления дребезга и чтения состояния.

Для тестовой прошивки хаба дополнительно включены неизменённые `LED.h`,
`PWM.hpp`, `PWMInit.hpp` и `Connector.hpp` из `tjc-ms1-main-a4/1.0/source/`
той же ревизии. Их SHA-256 закреплены в `scripts/build_hub.py` (`LED_FILES`);
они используются только целями `hub-test` и `buttons-test`. Эти четыре файла
также побайтно совпадают с `tjc-ms1-btn-a2/1.0/source/`: кнопочница использует
собственный исходный LED с той же картой PA5/PA6/PA7, не произвольные GPIO.
Из-за числовых литералов с разделителями
в upstream PWMInit.hpp тестовая цель компилируется как C++14.
Только для тестов скрипты `build_hub.py` / `build_buttons.py` инструментируют копию
UART.hpp: при RXNE увеличивается тестовый счётчик до чтения RDR/разбора SimpleBus.
Этот счётчик включает LED №2; принятый адресованный пакет включает LED №3,
который выключается после возврата `sendPacket()`.
Счётчики раздельные: hub_test::uart_rx_count / buttons_test::uart_rx_count.
Рабочие hub/buttons не получают ни счётчиков, ни LED/PWM-зависимостей.

Это исходники без локальных изменений. SHA-256 закреплены в
`scripts/build_gateways.py`; CRLF перед проверкой нормализуется в LF.
Сборка готовит копию в build и применяет существующие локальные исправления:
FIFO SimpleBus 64 байта, overflow, короткие IRQ-секции, безопасный побайтный
сдвиг UART и исправленная защёлка overflow ArduinoAdapter. Upstream-файлы
в firmware/runtime при сборке не изменяются. Подробности — docs/GATEWAY-FIRMWARE.md.
